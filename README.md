# WebDev_Project_TeamLucasSnow
#Project Description
This project is a website created for Lucas Snow showcasing his passion for snowboarding, winter sports and travelling to exciting destinations. 

The website will include:
- A Main Homepage with an exciting winter sports theme welcoming the users to the site.
- An About page where Lucas can share his story and love for winter sports, making the users feel intrigued and welcomed.
- A Navigation bar connecting the different pages together, making the website accessible and easy to use.
- The goal is to create an accessible, user friendly, exciting website that represents Lucas's passion.

The technologies I plan to use are:
- GitHub
- VScode
- HTML
- CSS
